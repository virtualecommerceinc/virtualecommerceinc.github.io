# VirtualEcommerce Inc. — virtualecommerceinc.com

Source for the flagship VirtualEcommerce Inc. marketing site (custom AI-powered websites + self-edit handoff).

Static site — pure HTML/CSS/vanilla JS, no build step. Served by GitHub Pages from `main` at the apex domain `virtualecommerceinc.com` (custom domain via `CNAME`).

## Pages

- `index.html` — Home
- `ai-advantage.html` — The AI Advantage
- `services.html` — Services
- `work.html` — Work / portfolio
- `pricing.html` — Pricing
- `about.html` — About
- `contact.html` — Contact / Book a Call
- `thank-you.html` — Post-contact-form confirmation
- `partners.html` — Preserved legacy page

## Preserved sub-sites

- `blog/` — legacy blog content
- `earbuds/` — legacy product micro-site

## Deploy

Push to `main` → GitHub Pages auto-publishes to https://virtualecommerceinc.com.

Do **not** delete `CNAME` (breaking it breaks the domain).
